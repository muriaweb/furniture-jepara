# Aurum Teak Jepara - Furniture Landing Page

Heritage Craftsmanship for Modern Living. Menyediakan furniture Jati premium berkualitas ekspor langsung dari pengrajin Jepara.

Project ini adalah *landing page* modern dan responsif yang dibangun menggunakan **Astro** dan **Tailwind CSS**.

## 🚀 Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Formatting**: Prettier

## 📁 Struktur Proyek

- `src/components/` - Komponen UI yang dapat digunakan kembali (Navbar, Hero, About, Collections, Testimonials, Footer, dll).
- `src/layouts/` - Layout utama halaman web.
- `src/pages/` - Halaman utama dan routing Astro.
- `src/styles/` - Gaya CSS global.

## 🛠️ Cara Menjalankan Proyek Secara Lokal

Pastikan Anda telah menginstal **Node.js** (versi >=22.12.0 disarankan).

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Jalankan Development Server**
   ```bash
   npm run dev
   ```
   Server akan berjalan di `http://localhost:4321/`.

3. **Build untuk Production**
   ```bash
   npm run build
   ```
   Hasil build akan berada di dalam folder `dist/`.

## 🎨 Menjaga Kerapian Kode

Proyek ini menggunakan Prettier untuk format kode. Anda bisa merapikan semua file dengan menjalankan:

```bash
npx prettier --write .
```
